# 🎙️ Локальная транскрибация аудио и видео

Streamlit-сервис для транскрибации аудио и видео **на своём компьютере**: по ссылке
(YouTube, подкасты, RSS-эпизоды) или из локального файла. Распознавание — локальные
модели [faster-whisper](https://github.com/SYSTRAN/faster-whisper), аудио никуда не
отправляется. Длинные записи обрабатываются в фоне с сохранением прогресса на диск,
поэтому многочасовые файлы можно ставить на ночь и продолжать после перезапуска.

[English version →](README.en.md)

## Возможности

- **Ссылка или файл.** YouTube и тысячи сайтов через
  [yt-dlp](https://github.com/yt-dlp/yt-dlp) (подкасты, SoundCloud, RSS), а также
  загрузка файла или путь к файлу на диске. Отдельно поддержан Castbox.
- **Готовые субтитры YouTube.** Если у видео есть субтитры (ручные или автосубтитры),
  они используются напрямую — без скачивания аудио и без нагрузки на CPU. Повторы
  «бегущей строкой» автоматически схлопываются, текст получается читаемым.
- **Локальные модели Whisper** `tiny` … `large-v3` (по умолчанию `small`), CPU `int8`,
  VAD-фильтр тишины, автоопределение языка.
- **Прогресс не теряется.** Каждый фрагмент сохраняется в `segments.jsonl`, состояние —
  в `state.json`. Задачу можно отменить и позже возобновить, даже после перезапуска
  сервиса.
- **Выгрузка** TXT, SRT, VTT с таймкодами и предпросмотром полного текста.
- **Изложение (LLM).** Опционально — краткое содержание и тезисы через OpenRouter
  (включая бесплатные модели), на русском или на языке оригинала. Для длинных
  записей используется map-reduce с защитой от зацикливания и потерей тезисов;
  изложение можно составить автоматически сразу после транскрибации.

## Требования

- **Python 3.10+** (проверено на 3.13).
- **ffmpeg** — нужен для конвертации аудио. Ставить вручную не обязательно: если
  `ffmpeg` нет в `PATH`, используется бинарь из пакета `imageio-ffmpeg`, который
  устанавливается вместе с зависимостями.
- Место на диске: модели Whisper скачиваются при первом запуске
  (~0.5 ГБ `tiny`/`base`, ~1 ГБ `small`, ~1.5 ГБ `medium`, ~3 ГБ `large-v3`),
  плюс WAV-копия записи (16 кГц моно ≈ 115 МБ на час).

## Установка

### Windows

```bat
git clone https://github.com/USER/REPO.git
cd REPO
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### macOS / Linux

```bash
git clone https://github.com/USER/REPO.git
cd REPO
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Если хочется использовать системный ffmpeg вместо поставляемого с пакетом:

- Windows: `winget install Gyan.FFmpeg`
- macOS: `brew install ffmpeg`
- Debian/Ubuntu: `sudo apt install ffmpeg`

## Запуск

**Windows:** двойной клик по `start.bat` — он найдёт Streamlit (в `PATH`, в
пользовательской Anaconda/Miniconda или через `python -m streamlit`), откроет браузер
и запустит сервис.

**Любая ОС:**

```bash
streamlit run app.py
```

Интерфейс: <http://localhost:8501>

## Как пользоваться

1. В боковой панели выберите модель Whisper, тип вычислений (`int8` для CPU), язык и
   включите/выключите VAD.
2. **📺 Брать готовые субтитры (YouTube)** — быстро забрать существующие субтитры
   вместо транскрибации. Если субтитров нет, автоматически выполнится обычная
   транскрибация.
3. **📝 Составить изложение после транскрибации** — после успешной транскрибации
   сразу составить изложение. Нужен API-ключ OpenRouter
   ([получить](https://openrouter.ai/keys)); модель по умолчанию — бесплатная
   `openrouter/free`. Ключ хранится только в памяти сессии и на диск не пишется.
4. Добавьте задачу: вкладка «Ссылка», «Локальный файл» или «Путь к файлу», затем
   **▶️ Начать транскрибацию**.
5. В карточке задачи видны канал, длительность, статус, прогресс и примерное время до
   конца. Готовый результат можно скачать в TXT/SRT/VTT, изложение — в Markdown.

## Как это устроено

| Файл | Назначение |
| --- | --- |
| `app.py` | интерфейс Streamlit, карточки задач, автообновление через `st.fragment` |
| `downloader.py` | загрузка по ссылке (yt-dlp), Castbox, готовые субтитры (VTT/SRT), конвертация в 16 кГц WAV |
| `transcriber.py` | faster-whisper, чанки с чекпоинтами, экспорт TXT/SRT/VTT |
| `jobs.py` | очередь задач, один фоновый рабочий поток, состояние в `jobs/<id>/` |
| `summarizer.py` | изложение через OpenRouter (map-reduce, ретраи, защита от зацикливания) |

Все данные хранятся локально в `jobs/<id>/`: `state.json` (состояние), `audio.wav`,
`segments.jsonl` (распознанные фрагменты), `transcript.txt/.srt/.vtt`, `summary.md`.
Кнопка «Удалить» стирает всю папку задачи.

## Частые вопросы и проблемы

- **Первый запуск долгий** — скачивается модель Whisper с Hugging Face.
- **`streamlit` не является командой** — активируйте виртуальное окружение
  (`.venv\Scripts\activate`) или запустите через `start.bat`.
- **`DLL load failed` / ошибки KMP** — сервис уже выставляет
  `KMP_DUPLICATE_LIB_OK=TRUE`; при ручном запуске сделайте так же.
- **Субтитры не скачались (HTTP 429)** — YouTube ограничивает частые запросы;
  сервис автоматически переходит к обычной транскрибации.
- **Изменения в `jobs.py`/`summarizer.py` не применяются** — Streamlit кэширует
  модули, перезапустите сервис.
- **Нет GPU** — всё рассчитано на CPU; `small` + `int8` — разумный баланс, для
  многочасовых записей берите `base`/`tiny`.

## Ограничения

- Работает на CPU: скорость примерно 0.3–1× от длительности записи в зависимости от
  модели и компьютера.
- Бесплатные модели OpenRouter могут быть перегружены и иметь небольшой лимит вывода;
  сервис повторяет запрос и сообщает об ошибке, если модель так и не ответила.
- Автосубтитры YouTube содержат ошибки распознавания имён и терминов — для важных
  записей лучше отключить готовые субтитры и прогнать Whisper.
